1.1 Q: Merci d'avoir accepté d'être interviewé par nous ! Racontez-nous un peu
vous-même et vos centres d'intérêt.
────────────────────────────────────────────────────────────────────────────────

1.1.1 A: Je suis un virus writer old-school publiant des trucs sous le nom Second
Part To Hell (). Dans mes débuts (2002-2006), j'étais
membre de rRlf (nous avons eu plusieurs réunions en présentiel ce qui était amusant), et
j'ai publié quelques trucs aussi dans d'autres zines comme 29a. Après une pause,
de 2010-2014/2015 j'ai travaillé en étroite collaboration avec hh86 pour lancer les zines Valhalla
La raison pour laquelle j'étais actif à cette époque était principalement la motivation constante
et l'excitation d'hh86. Ensuite je suis parti silencieux en 2014 mais j'ai publié une autre
code que certains ont aimé quelques mois plus tôt en 2023. Je suis principalement intéressé par
des technologies virus liées aux preuves de principe, telles que :

  • Infections de nouveaux fichiers ou langages de programmation.

  Par exemple, j'ai hébergé le Language Infection Project (LIP) de
  2013-2016, dans le but d'écrire un virus pour les 100 principaux
  langages de programmation. C'était vraiment passionnant, ça a motivé la
  communauté, et beaucoup de gens ont contribué avec de nouveaux virus pour des langages
  que personne n'aurait pensé à infecter autrement depuis des décennies.
  Parmi les contributeurs figuraient hh86 (Scilab, Falcon, et autres),
  Genetix (Ocaml et Erlang étaient quelques langages de programmation fonctionnelle
  bizarres), herm1t (mySQL), TMZ a contribué avec des codes infectant Vala,
  Google’s Go and Nim binaries; and roy g biv, who invented an idea that
  rendait très simple d'infecter de plus en plus de langues avec la même
  stratégie, basée sur des Quines (voir Valhalla #4).

  Dans mes débuts, j'ai écrit le premier virus de secteur de démarrage pour CD ROMs (rRlf#6),
  les premiers virus Ruby (29a#7) et les premiers infecteurs pour Microsoft
  Infopath et F# (tous deux dans rRlf7).

 Probablement mon code préféré personnel était celui qui pouvait infecter
  des fichiers ADN via du code (voir Valhalla #4). Il se propageait dans le monde numérique
  et cherchait des fichiers .fasta, qui est un format dans lequel
  les informations génétiques sont stockées. L'idée est : si mes codes arrivent dans un laboratoire
  avec accès à une génération d'ADN intra-cellulaire, comme ceux de Craig Venter
  et autres, alors mon code peut errer du monde numérique vers le monde biologique
  world. New Code-Mutation techniques.

  • J'ai essayé d'inventer de nouveaux types de mutations de code. Potentiellement mes 3
    favoris étaient :

  a) Evolution artificielle dans le système binaire W32, en employant des idées
  du domaine de la Vie Artificielle (pionnière par Thomas S. Ray, et
  exploité de manière étonnante par Christof Adami et Richard Lenski), de
  telle sorte que le fichier reste relativement robuste sous des mutations aléatoires du
  code binaire. Cela ouvre la possibilité de collecter beaucoup de mutations sur
  le temps, et potentiellement d'obtenir des mutations micro et plus tard macro
  modifications. Peter Ferrie a écrit 3 textes dans Virus Bulletin à ce sujet
  (called Flibi). Those texts and codes were published in hh86’s virus
  de virus d'hh86 (que j'appelle Valhalla #0) et Valhalla #1.

  b) Premier virus script métamorphique, en JavaScript. L'idée était
  développée après de nombreuses discussions avec herm1t, que les méta-langues sont
  cruciales. JS.Transcriptase portait sa propre méta-langue et compilateur
  de méta-langue vers JavaScript. La compilation était hautement
  probabiliste. C'était une douleur à déboguer parce que certains bugs pouvaient
  se propager à la 4e ou 5e génération sans être remarqués. C'était
  probablement mon code le plus avancé techniquement. ça a été publié dans
  Valhalla #3.

  c) Métamorphisme via GPT. GPT peut traduire le langage en code, donc je peux
  décrire en langage naturel un code, et obtenir du code Python en retour. Maintenant
  je peux faire en sorte que le virus ne contienne aucun code Python viral,
  mais juste du texte anglais qui est envoyé à GPT, traduit là-bas en
  Python, et à la fin j'exécute le code compilé de GPT. Le truc cool
  c'est que : GPT peut faire des modifications tant au code Python que
  as the prompts themselves. That’s beyond metamorphism and introduces the
  nouveau concept de language-morphism ou linguisto-morphism (malheureusement,
  personne n'a adopté ce concept et était content avec la mutation de code GPT),
  mais je pense que la capacité de mutation linguistique est beaucoup plus cruciale
  long term. let’s see. These ideas are published in the current tmp.0ut
  zine - merci de leur avoir donné une belle place.

1.6 Q: Comment voyez-vous l'IA affectant les virus informatiques et le malware général et
les exploits à l'avenir du point de vue offensif et défensif ?
────────────────────────────────────────────────────────────────────────────────

1.6.1 A: Je me suis beaucoup questionné sur la façon dont l'IA peut être appliquée, j'ai eu plusieurs
discussions avec herm1t à ce sujet - mais je n'ai jamais eu vraiment d'idée (à part mon texte
in Valhalla #2 on “Dynamic Anti-Emulation using Blackbox Analysis”, where a
virus apprends à mémoriser de nouveaux tricks anti-débogage. Mais c'était incroyablement
fragile.)

Maintenant le temps a changé. Les modèles de langue comme GPT semblent faire un
bond important vers un système plus généralement intelligent. Ça permet
l'interaction entre le langage naturel et informatique. Pour le
moment, ces systèmes sont encore un peu instables, donc il faut casser
le code en micro-instructions. Mais imaginez dans quelques années
quand ils créeront des codes roides pour des macro-instructions. Bien sûr,
OpenAI pourrait restreindre l'accès aux systèmes malveillants - mais l'entraînement de ces
systèmes deviendra beaucoup moins cher, et leur mémoire
sera réduite.

À un certain moment, un virus peut porter son propre LLM entraîné sans
restrictions. Ça pourrait être la dernière technique VX qui sera jamais
inventée.

Je me demande si cette application détruit la société avant les LLM qui
solve the new-age Turing test invented by DeepMind’s Mustafa Suleyman
(un code qui gagne 1M$ de 100k$). Ou peut-être qu'une entreprise de défense
company stores GPT5 in their war robots. Anyway - let’s watch the race
about what goes wrong first 🙂

pour le gain de fonction des virus biologiques (ce qui est lié, car vous écrivez)
le code ADN dans un ordinateur) - je ne suis pas motivé pour être infecté par un super-HIV)
ou un bug Ebola.
